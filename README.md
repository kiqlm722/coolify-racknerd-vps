## Coolify 最低配置：2 核、2GB、30GB 只是入场券

2 核 CPU、2GB 内存、30GB 可用磁盘空间，这是 Coolify 官方文档写明的最低要求，三项缺一不可。

## 在 RackNerd VPS 上装 Coolify 的完整流程

整个安装就是一条官方脚本的事，Docker 会一并装好：

1. 下单时系统选 Ubuntu 24.04 LTS（Debian 12 也可以）。机房建议洛杉矶或圣何塞——如果你主要从国内访问，美西节点的延迟通常比东部低不少。
2. SSH 登录服务器，执行 Coolify 官方安装脚本（以 Coolify 文档当前给出的命令为准）：

   
   curl -fsSL https://cdn.coollabs.io/installs/latest/install.sh | bash
   

   脚本开源可审查，会自动装 Docker 并拉起 Coolify，全程两三分钟。
3. 浏览器打开 `http://服务器IP:8000`，第一件事是注册管理员账号。全新安装时第一个访问面板的人会成为所有者，你的机器挂着公网 IP，这一步别拖。
4. 绑域名：A 记录指向服务器 IP，防火墙放行 80 和 443，Coolify 内置的 Traefik 会自动签发并续期 Let's Encrypt 证书。之后建议把 8000 裸端口在防火墙关掉，只走域名访问。
5. 在 Sources 里连接 GitHub 或 GitLab，新建应用选好仓库和分支，Nixpacks 会自动识别 Next.js、Laravel 这类框架，推代码即触发部署。
